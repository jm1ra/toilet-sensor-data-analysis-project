## NIT Capstone 1 AND Capstone 2 Project
Our task is to create a web application with a login page, home page and admin panel with functioning buttons for our project - the webpages should be able to allow the users to manage and filter data to view import dates to when the toilets are most being used, and average daily use.

**Our code is written using REACT and JS, you should be able to download all the files and run it within your VS Code terminal using the npm run dev command to create a server to view the webpages**

## How to run the node terminal:
1. Download React on your device (https://nodejs.org/en/download, downloading a prebuilt Node.js from an installer will work)
2. Run this command in your powershell ( Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned ) 
3. Run "npm install" (**MAKE SURE THIS COMMAND IS USING THE my-app DIRECTORY**)
4. Run "npm run dev"
5. Ctrl + Left click the local host link that the terminal provides you.

You can run npm install inside VS code's built in terminal, just make sure you are in the correct directory first,
if you are unsure about running the powershell command, that command only puts your devices user into developer mode.
You can undo the change with "Set-ExecutionPolicy -ExecutionPolicy Restricted"
